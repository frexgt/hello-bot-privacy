Эта политика описывает, как Discord-бот Hello Welcome Bot обрабатывает данные при приветствии новых участников сервера.

Какие данные используются

Бот обрабатывает только данные, которые Discord уже предоставляет при входе участника на сервер:

  • имя пользователя и отображаемое имя;
  • аватар;
  • идентификатор пользователя Discord;
  • название сервера и текущее количество участников.

Зачем это нужно

Данные используются только чтобы отправить приветственное сообщение с упоминанием участника и персональной обложкой в канал hello.

Хранение

Бот не сохраняет эти данные в своей базе, файлах или сторонних сервисах. Информация берётся из Discord в момент входа участника, используется для одного сообщения и не копируется отдельно.

Передача третьим лицам

Данные не продаются и не передаются третьим лицам. Бот работает через официальный Discord API.

Как отключить бота

Владелец сервера может в любой момент удалить бота или отозвать его доступ. После этого бот перестанет получать события и отправлять приветствия.

Контакты

По вопросам конфиденциальности напишите владельцу бота в Discord.

This policy explains how the Discord bot Hello Welcome Bot handles data when greeting new server members.

What data is used

The bot only processes data Discord already provides when a member joins:

  • username and display name;
  • avatar;
  • Discord user ID;
  • server name and current member count.

Why we use it

This data is used only to send a welcome message that mentions the new member and shows a personalized cover image in the hello channel.

Storage

The bot does not store this data in a database, files, or third-party services. It is read from Discord at join time, used for one message, and not copied elsewhere.

Third parties

We do not sell or share this data with third parties. The bot operates through the official Discord API.

How to disable the bot

A server owner can remove the bot or revoke access at any time. After that, it will stop receiving events and sending welcome messages.

Contact

For privacy questions, contact the bot owner on Discord.
